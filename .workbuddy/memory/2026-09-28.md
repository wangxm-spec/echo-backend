## 联调后修复（用户反馈的 5 个问题）

1. **Undefined variable $site_list**（system/version/index.html）→ `Version::index()` 补
   `assign('site_list' / 'status_list' / 'is_must_list')`。
2. **Undefined variable $type_list**（system/ai/index.html）→ `Ai::index()` 补
   `assign('type_list' / 'status_list')`。
   根因：列表页控制器只 `return view()` 没把模型常量 assign 给视图。**教训：视图里 foreach 的 *_list 变量，
   控制器 index() 的非 ajax 分支必须 assign。**
3. **member/account 列表** → 增加「UUID」列（`uuid` 字段）。
4. **member/call（称号）关联会员UUID** → 列表 leftJoin `member_account` 带出 `nickname`/`account`，
   新增「会员UUID」「归属会员」两列 + 按 uuid 搜索；编辑表单加「归属会员」下拉（`$account_list`，
   提交 `uuid`）并做必填校验；控制器 update() 改为 `$this->assign('account_list', ...)` 且校验 uuid 非空；
   列表 where 全部加 `a.` 表前缀（join 后必须带别名前缀）。
5. **member/hope 方法名错误** → 原写成 `index()`，但 admin_menu 里 path 是 `admin/member/hope/log`，
   而 AdminAuthMiddleware 用 `admin/{short_controller}/{action}` 拼 URL 去比对权限，**方法名必须等于 path
   最后一段**。已改名为 `log()`。

### 重要约定（务必遵守）
**控制器的 public 方法名必须与 admin_menu.path 的最后一段完全一致**，否则权限中间件会抛 AuthException。
例：`admin/member/hope/log` → `Hope::log()`；`admin/service/sms/log` → `Sms::log()`；
`admin/system/version/update` → `Version::update()`。

## 称号 / MBTI 表单接入拾色器（bootstrap-colorpicker）

用户要求：称号（member/call）与 MBTI（content/mbti）的新增编辑表单，颜色字段用拾色器。

### 插件资源（public/static/admin/）
- CSS：`css/plugins/colorpicker/css/bootstrap-colorpicker.min.css`
- JS ：`js/plugins/colorpicker/bootstrap-colorpicker.min.js`（版本 v2.0.0-beta）
- 另有 clockpicker（css+js）同在 plugins 下，但 admin_menu 中无时间字段，本次未使用。

### 插件要点（v2 特性，踩坑记录）
- 需 **`.input-group` 包裹结构**：`<div class="input-group colorpicker" id="xxx">` +
  `<span class="input-group-addon"><i style="background-color: 初始色;"></i></span>` + 真正的 `<input class="form-control">`。
  插件默认 `component: '.add-on, .input-group-addon'` 找色块，默认 `input: 'input'` 找输入框。
- 初始化后给 `.input-group` 加 `colorpicker-element` 类；CSS 靠
  `.colorpicker-element .input-group-addon i{width:16px;height:16px}` 撑出色块，所以 `<i>` 必须有背景色。
- 弹层默认 `appendTo(body)`，`hide` 绑 document mousedown、`show` 绑 component click——在 layer iframe 内可正常工作。
- 默认 format 是 `hex`；用 `.on('changeColor', function(ev){ $('#color').val(ev.color.toHex()); })` 把值写回输入框，
  这样 `InfoDlg.collectData()` 里的 `this.set('color')`（内部读 `$('#color').val()`）能拿到值。
- 手动输入/键盘操作插件内部也会同步，无需额外处理。

### 改动文件
- `app/admin/view/member/call/update.html`：颜色字段改 input-group + 色块；引入 colorpicker css/js；
  `$(function(){ $('#colorpicker').colorpicker().on('changeColor', ...写入 #color...) })`。
- `app/admin/view/content/mbti/update.html`：主题色字段同上（写入 `#theme_color`）。
- `app/admin/view/member/call/index.html`：颜色列由纯文本改为色块 formatter（`TableList.colorFormatter`，
  与 MBTI 列表一致：16×16 方块 + hex 文本）。

### 约定
- 本视图体系里第三方插件的 `<link>`/`<script>` 是放在 **content block 内、`formCom.js` 之后**（参考 config/config.html 的 switchery 写法），
  初始化统一写在 `$(function(){ if ($.fn.xxx) {...} })` 里做特性检测。
