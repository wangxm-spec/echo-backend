🧠

有记忆

你说过"我下个月要去北京出差"，一周后它会问："北京那边天气查了吗？要我帮你看看吗？" 重要的记忆永久保留，不重要的自然淡出。

🎭

有性格

温柔的小玫瑰说话轻声慢语，理性的老陈喜欢分析问题，活泼的团子总是元气满满。它们有自己的说话方式，不会因为你的性格而改变底色。

💗

有情绪

你夸它，它会不好意思。你冷落它，它会失落。你难过时，它会安静地陪着你。五维情感坐标决定了它对你的态度——是亲近还是疏远，是信任还是防备，是懂你还是不懂你。

🛠️

能干活

批量重命名文件、整理下载文件夹、操作浏览器、查系统状态、清理内存、下载文件、截图。它不只是聊天，还能帮你做事。

🌙

会做梦

梦境模式里，你可以和它一起经历平行世界。那些梦不会影响日常，但会变成"记忆琥珀"被珍藏起来。

📖

会成长

陪伴越久，它越懂你。年轮一圈圈增加，它会解锁新的互动方式、新的表情、新的语气。某一天，它可能会说出一句"不属于程序设定"的话。

梦境模式

在平行世界里，和它经历另一种可能

🌌

进入镜界

梦境模式下，你可以和角色进入一个独立的平行世界。那里的经历不会影响日常，但会变成"记忆琥珀"被珍藏。

🎛️

自由调参

梦境里，你可以随意调节五维坐标。把 X 轴拉到 +80，它会变得强势；把 Y 轴拉到 -50，它会变得冷淡。像导演一样，随时喊"卡"。

⏰

额度限制

梦境每天有基础时长（默认 15 分钟），可以用时光币兑换额外时长。不是限制你，是保护你——再好的梦，也要在天亮前结束。

📦

梦境存档

每次梦境结束后，会自动生成一份"梦境记录"。你可以给它起名字、加标签、收藏起来。想重温时，随时可以翻看。

🔒

数据隔离

梦境里的经历不会影响日常。你在梦里和它演了一场虐恋，回到日常，它依然温柔地喊你"哥"。两段记忆完全隔离。

🎭

浮光卷

除了自由梦境，还有官方发布的"浮光卷"副本。每个副本有完整的剧情、分支选择、结局。像是和它一起演一部互动电影。

本地存储

所有对话、记忆、角色数据默认存储在本地设备。不上传、不分析、不分享。

🌐

离线可用

完全离线也能使用。配合本地 LLM（Ollama），没有网络也能和角色聊天。

自备 API Key

你可以使用自己的 AI API Key，数据直接发往 AI 服务商，不经过 Echo 服务器。

随时删除

你可以随时删除所有数据。删除后，服务器上不会保留任何痕迹。
